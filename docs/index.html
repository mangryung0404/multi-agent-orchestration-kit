Run your CLI coding agents as one system, not a pile of tabs.

If you run more than one agent, you know these

  • A session dies mid-task and the next one starts from zero, re-deriving everything.
  • Worker output looked plausible, got merged, and was confidently wrong.
  • Claude can't see what Codex knows; Codex can't see what Gemini reviewed. Neither can you, three days later.
  • You paid three times for the same research because nobody remembered it was done.

The fix is boring on purpose: every task is a folder every tool can read, hard size caps keep agents attentive, an append-only log survives every crash, and no worker output is accepted without a verification pass.

The shape of it

Orchestrator (your interactive session: thinks, routes, verifies)
└── Worker Pool (headless, each call approved)
    ├── implementer   main build work
    ├── critic        adversarial review (read-only, other vendor)
    └── researcher    external facts

tasks/<task-name>/
├── task.md        goal, status, approvals     (the contract)
├── context.md     snapshot of NOW, ≤300 words (the state)
├── log.md         append-only, tagged         (the truth)
└── workers/<role>/brief.md + result.md       (the calls)

Works with Claude Code, Codex CLI, Gemini CLI, and local models: the orchestrator is whatever you drive by hand, workers are whatever you can call headlessly. Extracted from a system I run daily on real projects.

FAQ

Is this a framework or library?No. Markdown templates and operating rules. There is nothing to install, which is also why it survives vendor updates.
Do I need multiple paid subscriptions?No. The pattern works with one orchestrator and a single worker; roles matter more than headcount. Multi-vendor makes the critic sharper (cross-vendor review catches what same-model review agrees with), but it's optional.
Why not a vector store / memory MCP?For task-scoped orchestration state, files are readable by every tool including you, diffable, git-versioned, and crash-proof. Nothing else has all four.
Who wrote this?A solo builder running Claude Code as orchestrator over Codex, Gemini and a local model, daily, in public. The playbook's failure-modes chapter is my own incident list, generalized.
